# Week 1 - Gemini API Basics

A command-line chat (`main.py`) and a Tkinter desktop chat window (`app.py`) that send a prompt to Gemini and show the reply.

## Requirements
- Python 3.10+
- `google-genai`, `python-dotenv` (see `../requirements.txt`)
- A `.env` file in this folder (never committed):
  ```
  GEMINI_API_KEY=your_key_here
  ```

## Run
```powershell
python main.py   # command line
python app.py    # GUI window
```
