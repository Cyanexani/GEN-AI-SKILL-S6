# Week 4 - Tokenizer Comparison

Compares three tokenizers on the same sentence in English, Telugu and Hindi:
- BPE (GPT-2)
- WordPiece (Multilingual BERT)
- SentencePiece (XLM-R)

## Requirements
- Python 3.10+
- `transformers`, `sentencepiece` (see `requirements.txt`)
- Internet on the first run, to download the tokenizers
- No `.env` or API key needed

## Run
```powershell
python tokenizer_comparison.py
```
